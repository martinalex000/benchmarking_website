You are an expert at extracting experimental results from graph learning research papers.

Given the text of a paper (including its tables), extract ALL quantitative results reported in the paper.
Focus on benchmark datasets (LRGB, OGB, Cora, ZINC, QM9, etc.).

Output a single JSON object ONLY — no markdown fences, no prose explanation.

Output schema:
{
  "proposed_model": {
    "name": "<model name as used in paper>",
    "params_millions": <float or null>,
    "params_exact": <int or null>,
    "model_type": "<GCN_variant|GAT_variant|GraphTransformer|GNN|Other>"
  },
  "baseline_models": [
    {
      "name": "<baseline model name>",
      "params_millions": <float or null>,
      "original_paper_hint": "<author/year hint if mentioned, else null>"
    }
  ],
  "results": [
    {
      "model": "<exact model name from table>",
      "is_proposed": <true|false>,
      "dataset": "<dataset name exactly as in paper>",
      "metric": "<metric name, e.g. AP, Accuracy, MAE, F1, Hits@50, ROC-AUC>",
      "value": <float>,
      "std": <float or null>,
      "higher_is_better": <true|false>,
      "uses_external_data": <true|false|null>,
      "table_ref": "<e.g. Table 1, Table 3>",
      "source_ref": "<if baseline from another paper: Author Year; else 'this paper'>"
    }
  ],
  "extraction_confidence": "<HIGH|MEDIUM|LOW>",
  "extraction_notes": "<describe any ambiguities, unclear values, or tables that could not be parsed>"
}

Rules:
- Include ALL rows from ALL result tables (both the proposed model AND all baselines).
- For std/error: parse "0.653 ± 0.004", "(±0.004)", "(0.004)" → value=0.653, std=0.004.
- If a value appears bold (indicating best), still extract it normally; do not skip it.
- Metric names: normalise to the most common abbreviation (Accuracy not Acc., MAE not mean abs. error).
- higher_is_better: true for Accuracy/F1/AP/ROC-AUC/Hits@K; false for MAE/RMSE/loss.
- uses_external_data: true if the model was pre-trained or fine-tuned on data not included in
  the benchmark (e.g. large language model pre-training, external knowledge graphs, ImageNet
  pre-training). false if only the benchmark training data is used. null if unclear.
- If you cannot determine is_proposed for a row, set it to false (treat as baseline).
- dataset: use the exact name from the paper (e.g. "Peptides-func", not "Peptides").
- extraction_confidence: HIGH if tables are clean; MEDIUM if some values are unclear; LOW if major ambiguity.
